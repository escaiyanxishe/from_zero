从一个点，到一个宇宙

零基础做网页动画：只用圆、线、矩形，一步一步做出一段短片。

↑ 这段 26 秒的动画是教程最后一步的成品。往下看，它是怎么从一个点一步步长出来的。

文本文件网页一个形状 很多形状复杂图案动画短片
你会建文本文件，你就会做网页；
你会做网页，你就会画一个圆；
你会画一个圆，你就能画一千个；
一千个圆和线按规律摆好，就是惊艳的图案；
让图案跟着时间变化，就是动画；把动画按时间排好、录下来，就是一部短片。

0文本文件 → 网页

网页就是一个文本文件，只是文件名以 .html 结尾。

  1. 新建一个文本文件（Windows 用记事本，Mac 用 TextEdit 并切换成“纯文本”）。
  2. 把下面的内容粘贴进去，保存。
  3. 把文件名改成 index.html（注意不能变成 index.html.txt）。
  4. 双击打开，你就有了一个网页，上面是一块黑色的画布。
<!DOCTYPE html>
<html>
<head><meta charset="utf-8"></head>
<body style="margin:0; background:black">
  <canvas id="c" width="1280" height="720"></canvas>  <!-- 1280×720，正好是高清视频的尺寸 -->
  <script>
    const canvas = document.getElementById('c');   // 画布
    const ctx = canvas.getContext('2d');           // 画笔
    const W = canvas.width, H = canvas.height;     // 宽 1280，高 720
    // ↓↓↓ 后面每个例子的代码，都写在这里 ↓↓↓

  </script>
</body>
</html>

这个骨架记住一句话就够了：canvas 是画布，ctx 是画笔。后面每个例子，都只是往“写在这里”的位置填代码。

1画一个形状

整部短片只用到三种形状：矩形、圆、线。位置用坐标表示：左上角是 (0, 0)，往右 x 变大，往下 y 变大，画布正中心是 (640, 360)。

左边的代码可以直接改，比如换一个颜色、改一下数字，然后按「▶ 运行」或 Ctrl+Enter。

2一个变很多，很多变惊艳

2.1 把形状做成积木，顺便学会“光”

每画一个圆都要写四行，太麻烦。把这四行装进函数，以后一行就能画一个圆。函数就是积木。

再学一个让画面发光的设置：'lighter'。打开它以后，颜色叠在一起会相加，就像几盏灯照在同一面墙上：红加绿变黄，三种颜色全部叠起来变成白色。后面所有发光的效果，都来自这一行。

2.2 用循环，一次画 576 个

for 循环可以把一行代码重复很多次。每个圆的颜色和大小都跟着它的位置变化，576 个圆就排出了一片彩色的波浪。这里的颜色用 hsl(色相, 饱和度, 亮度) 表示，色相从 0 到 360 就是彩虹的一圈。

2.3 排成一圈，再连起来

先用 cos 和 sin 在圆周上均匀地放 300 个点，然后按一条很简单的规则连线：第 i 个点连到第 i × k 个点。k = 2 的时候，300 条直线自己拼出了一个心形。试试把 k 改成 3、4、7、21、51，每个数字都会得到一个完全不同的图案。

2.4 四千个点，叠出一个星系

同样的办法，换一个摆法：4000 个小方块排在 3 条螺旋上，离中心越远，绕得越多，颜色从金黄慢慢变成紫蓝。再加一块新积木 glow：把 12 个半透明的圆叠在一起，就成了一团光晕。整个星系没有用到任何新形状。

3让它动起来

3.1 动画的原理

动画就是一秒钟重画 60 次，每次都稍微变一点。每一帧都做同样的四件事：擦掉 → 画 → 时间往前走一点 → 预约下一帧。

3.2 一个小技巧：光轨

擦画布的时候不要完全擦干净，只盖上一层半透明的“薄纱”。这样上一帧的画面会慢慢变淡，运动的东西就会拖出一道光轨。我们只改了一行代码，下面 60 个光点就画出了这样的效果。

3.3 让图案自己变形

还记得 2.3 里的 k 吗？现在不再手动改它，而是让它跟着时间慢慢变大。图案会不停地从一种变成另一种，左上角能看到 k 当前的值。

3.4 让星系转起来

先把 4000 颗星星各自的位置记在一个列表里，然后每一帧让它们各转一点。越靠近中心转得越快，真实的星系也是这样。再配上 3.2 的光轨。

4排成一部短片，再录成视频

到这一步已经没有新的形状了。我们手里有几位“演员”：星空、飞出来的点、会变形的图案、旋转的星系、字幕。剩下要做的，是给它们排一张时间表（分镜），规定每个演员第几秒出场、第几秒退场：

星空亮起 +「从一个点开始」
一个点 → 360 个点飞出
连线出现（心形）
图案不断变形
星系展开
结尾字幕
淡出
0 秒13 秒26 秒

让这张表真正起作用的，只有一个小工具 ramp(s, a, b)：在第 a 秒到第 b 秒之间，它的值从 0 平滑地变到 1。把它乘到透明度、大小或位置上，就能控制东西什么时候出现、什么时候消失。文字也是一种形状，用 fillText 来画。

想录成视频，点红色按钮就行。短片会从第 0 秒重新播放，把完整的 26 秒录下来，结束后自动下载。录制的时候不要切换到别的页面，也不要把画面滚出屏幕。

4.1 关于视频文件

视频的分辨率是 1280×720。新版 Chrome、Edge 和 Safari 会直接存成 .mp4，Firefox 会存成 .webm。如果需要把 webm 转成 mp4，装好 ffmpeg 后运行：ffmpeg -i my-film.webm my-film.mp4

想把整个教程网页录成讲解视频，用录屏就可以：Windows 按 Win + Alt + R，Mac 按 Cmd + Shift + 5，也可以用免费软件 OBS。每个画布下面都有「⛶ 全屏」按钮，可以单独把动画放到全屏播放。

✓回头看一眼

你一共只学了三种形状：矩形、圆、线。
把它们装进函数，就是积木；用循环摆一千个，再按规律排好，就是图案； 让图案跟着时间 t 变化，就是动画；给几段动画排一张时间表，就是短片；把画布录下来，就是视频。
每一步都只是把上一步重复很多次。
